Automated Circuit Analysis Using DAQ & Python

A project focused on automating current-voltage measurements for resistors and LEDs using LabVIEW, an NI USB-6003 data-acquisition device, and Python-based analysis.

Aug. 2025 – Dec. 2025 LabVIEW NI USB-6003 Python

Project Overview

This project was developed to replace slow manual digital-multimeter measurements with an automated current-voltage testing workflow. Using LabVIEW and an NI USB-6003 data-acquisition device, I created a system that performed voltage sweeps, collected electrical data, and supported automated analysis in Python.


The system was used to characterize Ohmic resistors and non-Ohmic red, blue, green, and infrared LEDs. This project generated more than 45 datasets across multiple resistance values and diode trials.

Project Goal

Why Automation?

Manual DMM measurements were time-consuming and made it difficult to collect large, repeatable datasets.

What Was Built?

An automated LabVIEW-based measurement system using NI USB-6003 hardware for voltage sweeps and data collection.

What Was Measured?

Current-voltage behavior of resistors and multiple LEDs, followed by analysis in Python.

System Workflow

1. Set Voltage Sweep

Define the start voltage, end voltage, step size, and measurement delay in LabVIEW.

2. Apply Voltage

Use the NI USB-6003 to apply a sequence of voltages to the device under test.

3. Measure Response

Acquire voltage and current measurements for the resistor or LED during the sweep.

4. Analyze Data

Process datasets in Python using pandas, matplotlib, and SciPy for plotting and interpretation.

Hardware & Software

Hardware

NI USB-6003, breadboard circuits, multimeters, power supply, resistor decade box, and LEDs.

Software

LabVIEW for automation and DAQ control, Python for data analysis, plotting, and comparison.

Experimental Scope

15 resistance values, multiple LED types, and repeated trials to examine repeatability and device behavior.

Key Results

45+ Datasets

Generated high-resolution datasets across resistor and LED experiments.

15 Resistance Values

Automated characterization performed across a wide range of resistor values.

R² > 0.99

Resistor current-voltage curves showed strong linear agreement during analysis.
